# Financial Modelling Portfolio

This repository contains selected financial models completed by Prasad Lambor for learning and portfolio purposes.

The portfolio focuses on:

- Investment modelling
- Valuation
- Project finance
- Financial forecasting
- Debt and returns analysis

Each model is stored in a separate folder with its own README, Excel workbook and relevant supporting materials.

## Skills Demonstrated

- Financial modelling
- Investment analysis
- Valuation
- Project finance modelling
- Cash flow forecasting
- Debt sizing and repayment schedules
- Scenario and sensitivity analysis
- Excel modelling

## Disclaimer

The models in this repository are provided solely for educational and portfolio purposes. They should not be relied upon for investment, financing or commercial decisions.
