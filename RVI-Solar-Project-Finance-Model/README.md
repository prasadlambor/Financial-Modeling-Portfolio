# RVI Solar Project Finance Model

## Overview

This model evaluates a hypothetical 150 MWp utility-scale solar PV project operating under a 30-year Power Purchase Agreement.

It was independently completed by Prasad Lambor using the publicly available Project Finance Modelling Test developed by the Renewables Valuation Institute (RVI).

## Model Scope

The model includes:

- Energy generation and revenue forecasting
- Operating expenditure projections
- Depreciation and corporate tax
- DSCR-based debt sizing
- Fixed and floating interest calculations
- Debt repayment schedule
- Project and equity cash flows
- Unlevered pre-tax Project IRR
- Unlevered after-tax Project IRR
- Levered Equity IRR
- Net Present Value
- Annual Cash-on-Cash Yield
- Total Cash-on-Cash Multiple
- Equity Payback Period

## Attribution

The case-study assumptions and SOFR forward curve were provided as part of RVI's publicly available modelling exercise.

The model structure, formulas, calculations, debt sizing, return analysis and presentation were completed independently by Prasad Lambor.
